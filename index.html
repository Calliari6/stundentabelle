Stundentabelle verbinden

Deine Stunden liegen in einem privaten GitHub-Repo. Dieses Gerät braucht dafür einmalig einen Zugangsschlüssel.

Wie bekomme ich den Schlüssel?
  1. Auf GitHub einen neuen Schlüssel erstellen (Fine-grained token).
  2. Repository access: Only select repositories → dein Daten-Repo.
  3. Permissions → Repository → Contents: Read and write.
  4. Generate token, kopieren und hier einfügen.

Der Schlüssel bleibt nur auf diesem Gerät gespeichert und gilt nur für das Daten-Repo.
